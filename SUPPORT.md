# Support

This is an experimental community project, not an official Logitech or
Microsoft product.

Use [GitHub issues](https://github.com/digitarald/mx-keypad-ahp-bridge/issues)
for reproducible bugs and focused feature requests. Include relevant versions
and sanitized logs, but never include AHP tokens or private session content.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
